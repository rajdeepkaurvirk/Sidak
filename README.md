# Sidak & Alam: wedding countdown

A static page, so it works on GitHub Pages with no build step.

## Publish
1. Put `index.html`, `style.css`, `script.js` and the `assets/` folder in a GitHub repo.
2. Settings → Pages → Deploy from branch → `main` / root.
3. Your site appears at `https://<username>.github.io/<repo>/`.

## Edit
- **Date:** change `WEDDING` at the top of `script.js` (local time).
- **Names / date line:** edit them in `index.html`.
- **Colors:** the palettes are `P` (roses) and `LEAF` in `script.js`; text colors are in `style.css`.
- **Your own painting:** save an image as `assets/backdrop.jpg` (best at 9:16, e.g. 1080×1920). It replaces the drawn garden; the countdown and glitter stay on top.
